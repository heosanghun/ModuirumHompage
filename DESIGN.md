## Brand & Style

This design system embodies sovereign, mission-critical computational supremacy. Built for air-gapped defense architectures, high-frequency financial ledgers, and zero-leak bio-synthesis pipelines, the interface conveys absolute mathematical certitude, technological authority, and kinetic computational power. 

The aesthetic synthesizes **Cybernetic Defense-Tech** with **Aerospace Precision Instrumentation**. It rejects generic, playful SaaS tropes in favor of monolithic dark fields, surgical optical guides, hairline telemetry dividers, and luminous cryogenic phosphor accents. Every element projects the rigor of a hardware-secured cryptographic terminal combined with the executive prestige of an aerospace command display. Interfaces must evoke quiet confidence, deterministic latency, and impenetrable integrity.

## Colors

The chromatic architecture is anchored by high-density dark surfaces punctuated by tactical energy emitters:

- **Primary (`#00F2FE` - Cryo Cyan):** The primary optical vector. Signifies active compute states, neural convergence, primary call-to-actions, and live telemetry nodes.
- **Secondary (`#00FF87` - Audit Emerald):** Cryptographic verification, zero-residual proofs, verified enclave integrity, and hardware-attested state validation.
- **Tertiary (`#38BDF8` - Stratosphere Blue):** Auxiliary metrics, floating data readouts, secondary selections, and structural focus rings.
- **Neutral Palette:**
  - `Void Base (#0A0D14)`: Deepest canvas level; foundational background for all mission consoles.
  - `Obsidian Elevated (#0F172A)`: Primary surface for panels, floating hardware trays, and secure enclaves.
  - `Enclave Slate (#1E293B)`: Structural borders, hairline grid intersections, and inactive state fills.
  - `Sub-Tactical Gray (#64748B)`: De-prioritized telemetry labels, passive units, and hardware IDs.
  - `Pure Signal (#F8FAFC)`: Dominant optical typography for deterministic data parsing.

### Functional States
- **Alert / Breach Hazard (`#FF3366`):** Air-gap compromise, parity errors, and memory overflow alerts.
- **Warning / Divergence (`#F59E0B`):** Equilibrium drift, high iteration counts, and thermal throttling.

## Typography

The typographic hierarchy coordinates three functional typefaces:

1. **Space Grotesk (Headlines & Hero Metrics):** Geometric, authoritative, structural. Delivers the tactical, forward-looking punch required for high-level capability assertions and critical telemetry readouts.
2. **Geist (Body & Documentation):** Ultra-refined, low-distortion, neutral grotesque engineered for optimal scanning speeds across complex structural data and defense-grade system manuals.
3. **JetBrains Mono (Labels, Hashes, Verification Proofs, Telemetry):** Strict, tabular monospace performance. Used universally for SHA-256 validation signatures, constant-memory O(1) indicators, execution addresses, and hardware status labels. All monospaced labels must use uppercase or strict tabular numerals (`font-feature-settings: 'tnum' 1`).

## Layout & Spacing

The layout is constructed on an authoritative **12-column tactical engineering grid** optimized for multi-pane telemetry, real-time convergence plots, and hardware monitor split-screens.

- **Desktop (1440px+):** 12-column grid, `margin-desktop` (48px), `gutter-desktop` (24px). Accommodates dense operational dashboards, real-time memory heatmaps, and continuous status ribbons without scroll reliance.
- **Tablet / Secondary Ops (768px - 1439px):** 8-column layout, 24px margins, 16px gutters. System health monitors collapse into collapsable sidebar trays.
- **Mobile Tactical Terminal (320px - 767px):** 4-column layout, `margin-mobile` (16px), `gutter-mobile` (12px). Heavy data matrices convert into linear cryptographic event feeds with tabbed view selectors.

The vertical rhythm strictly respects the 4px baseline. Section boundaries are demarcated by fine-line structural borders (`#1E293B`) rather than excessive empty whitespace, preserving an efficient, command-center information density.

## Elevation & Depth

This system avoids soft, decorative shadows in favor of **Tonal Enclaves, Tactical Glassmorphism, and Laser-Edged Luminescence**:

- **Ground Level (Elevation 0 - `#0A0D14`):** Raw system canvas, completely matte, absorbing all light.
- **Enclave Panel (Elevation 1 - Surface):** `#0F172A` at 70% opacity backed by `backdrop-filter: blur(16px)`. Bordered by a razor-thin 1px border (`#1E293B`).
- **Active Tactical Deck (Elevation 2 - Floating Modals & Hover States):** Surface shifts to `#1E293B` at 85% opacity with an ambient inner glow (`inset 0 1px 0 0 rgba(0, 242, 254, 0.2)`).
- **Photonic Focus & State Elevation:** Active execution states emit targeted, cryogenic box glows:
  - Primary Active: `0 0 20px -4px rgba(0, 242, 254, 0.35)`
  - Verification Confirmed: `0 0 20px -4px rgba(0, 255, 135, 0.35)`
- **Corner Tick Overlays:** High-security panels utilize subtle 4px L-shaped corner guides (`#38BDF8`) to reference precision optical HUD targeting systems.

## Shapes

The design system employs a **Soft Precision (`roundedness: 1`)** geometry. 

Corners are slightly mitigated (4px default, 8px maximum for oversized enclaves) to preserve a machined, hardened appliance aesthetic without the fragility of pure 0px wireframes. 

- **Micro Controls, Inputs & Badges:** `border-radius: 2px` to `4px`.
- **Enclave Cards & Console Modules:** `border-radius: 4px` with a mandatory `1px` uniform border.
- **Verification Pills & Telemetry Nodes:** Restricted strictly to technical pill shapes (`9999px`) only when indicating binary cryptographic status (e.g., `ATTESTED`, `O(1) LOCKED`).
- **Tactile Chamfers:** In hardware configuration panels, elements may utilize subtle 45-degree angled chamfers (clipped corners via CSS `clip-path`) on the top-right corner to reinforce defense-spec hardware physicalization.

## Components

### 1. Primary Action & Command Triggers
- **Primary Cybernetic Button:** Solid fill utilizing a cryogenic linear gradient (`linear-gradient(135deg, #00F2FE 0%, #38BDF8 100%)`), dark obsidian label (`#0A0D14`), uppercase monospace tracking (`JetBrains Mono`, 12px, weight 600). Hover state introduces an external radiant aura (`0 0 24px rgba(0, 242, 254, 0.5)`).
- **Secondary Air-Gap Button:** Transparent base, 1px perimeter border in `#1E293B`, type in `#00F2FE`. Hover state transitions border to `#00F2FE` and fills the backdrop with `rgba(0, 242, 254, 0.05)`.

### 2. Cryptographic Proof Badges & Audit Chips
- **Structure:** Monospaced label flanked by a pulsing 6px hardware indicator dot.
- **Audit Verified Badge:** Background `rgba(0, 255, 135, 0.08)`, border `1px solid rgba(0, 255, 135, 0.3)`, text `#00FF87`. Features a secondary hover tooltip rendering zero-knowledge proof hash and node attestation stamp.
- **Constant Memory O(1) Chip:** High-contrast tactical badge with cyan hairline outline and `#00F2FE` monospace glyph.

### 3. Data Inputs & Parameter Fields
- **Container:** Dark surface `#0A0D14` set within a `#1E293B` 1px border. Font `JetBrains Mono`, 13px, color `#F8FAFC`.
- **Focus State:** Border shifts sharply to `#00F2FE` with zero transition delay, backed by an inner subtle tint `box-shadow: inset 0 0 8px rgba(0, 242, 254, 0.15)`. Labels sit top-left with monospace micro-tags.

### 4. Binary Switches & Enclave Checkboxes
- **Checkboxes:** Squared 16x16px boxes, 2px border radius. In checked state: background `#00F2FE`, border `#00F2FE`, bearing a pure `#0A0D14` tactical checkmark.
- **Air-Gap Kill Switches:** Heavy-duty slide toggle. Housing: `#0F172A` with etched perimeter. Active state illuminates thumb with `#00FF87` and a soft green operational glow.

### 5. Tactical Enclave Cards & Hardware Displays
- **Panel Construction:** Backplate `#0F172A` at 80% opacity with `backdrop-filter: blur(12px)`. Outlined in 1px `#1E293B`.
- **Header Structure:** Segregated by a 1px continuous horizontal divider, containing terminal title on the left and real-time execution latency (`< 0.42ms`) on the right in `#64748B`.

### 6. Domain-Specific Component: Real-Time Convergence Streamer
- Real-time Deep Equilibrium (DEQ) iteration solver visualizer. Multi-layer oscilloscope graph mapping fixed-point iterations $f(z^*) = z^*$ to zero residual, backed by a dynamic SVG grid with real-time audit trail breadcrumbs in `#00FF87`.
